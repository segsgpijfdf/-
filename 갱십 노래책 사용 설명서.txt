갱십 노래책 사용 설명서
스트리머용 · 처음 설치부터 방송 종료까지
작성 기준: 2026년 9월 16일
============================================================

[먼저 알아둘 것]
이 노래책은 공개 웹사이트와 관리자 화면, OBS 오버레이로 구성됩니다.
평소 방송 운영에는 개발자의 컴퓨터나 로컬 서버가 필요하지 않습니다.
아래 운영 사이트에 접속해 스트리머 PC에서 사용할 수 있습니다.
서버 설치나 개발 프로그램 실행은 필요하지 않습니다.
단, MR 가사 동기화와 자동 가사 작업에는 관리자 화면을 열어 두어야 합니다.

운영 사이트: https://g12songbook.vercel.app/
관리자 화면: https://g12songbook.vercel.app/admin
로그인 화면: https://g12songbook.vercel.app/login
신청곡 OBS 주소: https://g12songbook.vercel.app/overlay/requests
가사 OBS 주소: https://g12songbook.vercel.app/overlay/lyrics
MR 브리지 설치 주소: https://g12songbook.vercel.app/playback-bridge.user.js



1. 처음 사용할 때 준비할 것
------------------------------------------------------------
처음 설치할 때 필요한 것:
  - 관리자 로그인 이메일과 비밀번호
  - Chrome 브라우저
  - Tampermonkey 확장 프로그램
  - OBS Studio
  - 최신 채팅 신청 스크립트: song_request.user.js (1.3.0 이상)
  - MR 재생 브리지: songbook-mr-playback-bridge.user.js
  - 채팅 스크립트 연결 정보(설치 파일에 미리 입력되어 있으면 별도 입력 불필요)

관리자 로그인 정보와 키는 이 설명서에 넣지 않았습니다.
로그인 정보와 설치 파일은 노래책 제작자에게 별도로 전달받으세요.
채팅 스크립트에는 공개 anon key만 넣습니다.

전달받을 설치 파일:
  song_request.user.js : SOOP 채팅의 신청 명령을 읽는 스크립트
  songbook-mr-playback-bridge.user.js : YouTube 재생과 가사를 연결하는 스크립트
MR 브리지는 위 설치 주소에서도 받을 수 있습니다.
채팅 감지기 파일은 반드시 현재 사용하려는 최신 버전인지 확인하세요.

처음 쓰는 PC에서는 2~4번을 한 번 설정합니다.
그 이후 매 방송은 5번 순서대로 진행하면 됩니다.


2. Chrome / Tampermonkey 설치
------------------------------------------------------------
1) Chrome에서 Tampermonkey 공식 사이트에 접속합니다.
   https://www.tampermonkey.net/
2) Chrome용 공식 확장 프로그램을 설치합니다.
3) Chrome 확장 프로그램 관리에서 Tampermonkey의 세부정보를 엽니다.
4) '사용자 스크립트 허용' 항목이 보이면 켭니다.
   브라우저 버전에 따라 개발자 모드 설정이 필요할 수 있습니다.
   공식 안내: https://www.tampermonkey.net/faq.php?locale=en&q=Q209
5) 대상 사이트에서 확장 프로그램 실행이 허용되어 있는지 확인합니다.

관리자 화면과 YouTube 재생 탭은 반드시 같은 Chrome 프로필에서 여세요.
예: 관리자=Chrome 개인 프로필, YouTube=다른 프로필이면 연결되지 않습니다.
OBS 자체 브라우저에는 Tampermonkey를 설치하지 않습니다.
OBS는 화면 표시만 하고, 실제 MR 재생은 Chrome의 YouTube 탭에서 합니다.


3. MR 재생 브리지 설치
------------------------------------------------------------
1) 운영용 Chrome에서 다음 주소를 엽니다.
   https://g12songbook.vercel.app/playback-bridge.user.js
2) Tampermonkey 설치 화면이 나오면 설치합니다.
3) 코드만 보이면 Tampermonkey 대시보드에서 새 스크립트를 만들고,
   파일 전체 내용을 붙여 넣어 저장합니다. 기본 예제 코드는 지웁니다.
4) 'Songbook MR Playback Bridge'가 켜져 있는지 확인합니다.
5) 이미 열려 있던 관리자 화면과 YouTube 탭을 새로고침합니다.

이 스크립트에는 별도의 API 키 입력이 필요 없습니다.
위 운영 사이트와 일반 YouTube 페이지에서 사용합니다.
나중에 노래책 주소가 바뀌면 새 주소에 맞는 설치 파일을 전달받으세요.

MR 동기화에는 위 MR Playback Bridge를 사용하세요.


4. SOOP 채팅 신청 감지기 설치
------------------------------------------------------------
1) Tampermonkey에서 새 스크립트를 만듭니다.
2) 전달받은 song_request.user.js 전체 내용을 붙여 넣습니다.
3) 연결 정보가 미리 입력된 파일이면 그대로 사용합니다.
   예제 값만 있다면 파일 위쪽 CONFIG의 두 값을 전달받은 값으로 바꿉니다.
   어떤 값을 넣을지 모르면 임의로 입력하지 말고 설정된 파일을 요청하세요.

   SUPABASE_URL: Supabase 프로젝트 주소
   SUPABASE_ANON_KEY: 해당 프로젝트의 공개 anon key

4) 저장하고 스크립트를 켭니다.
5) 같은 운영용 브라우저에서 https://play.sooplive.com/ 방송 페이지를 엽니다.
6) 이미 열려 있었다면 SOOP 페이지를 새로고침합니다.
7) 관리자 > 신청곡 관리에서 '채팅 신청 허용'을 켭니다.
8) 새 채팅으로 신청 명령을 보내 실제 목록에 추가되는지 확인합니다.

현재 스크립트 적용 도메인은 play.sooplive.com입니다.
다른 채팅 주소에서는 동작하지 않을 수 있으니 위 방송 페이지를 사용하세요.

신청 명령:
  !신청 곡명
  !신청 가수 - 곡명

예:
  !신청 첫사랑
  !신청 백아 - 첫사랑

선택 규칙:
  - 등록된 곡명 또는 별칭과 일치하는 곡을 찾습니다.
  - 대소문자와 공백 차이는 무시합니다. 임의 오타를 추측하는 검색은 아닙니다.
  - 같은 제목이 여러 개면 가장 최근에 부른 날짜의 곡으로 신청합니다.
  - 부른 기록이 없는 곡은 뒤로 밀립니다.
  - 원하는 가수가 따로 있으면 '가수 - 곡명'으로 지정하세요.
  - 등록되지 않은 곡은 추가되지 않습니다.
  - 같은 방송에서 같은 신청자의 같은 곡이 대기/진행 중이면 중복 접수되지 않습니다.

Soop 방송 페이지의 채팅창이 켜져 있어야 수집됩니다.
감지기는 켜진 뒤 새로 들어온 채팅을 처리합니다.
이미 화면에 있던 과거 채팅은 재접수하지 않습니다.
신청 성공/실패를 채팅으로 자동 답변하지는 않습니다.
관리자 신청곡 목록에 실제로 들어왔는지 확인하세요.
여러 PC/탭에서 동시에 감지기를 켜지 말고 운영용 한 곳에서 실행하세요.

스크립트 업데이트:
  - 기존 CONFIG 연결값을 따로 보관합니다.
  - 최신 파일 내용으로 교체하고 CONFIG를 다시 넣어 저장합니다.
  - SOOP 페이지를 새로고침합니다.


5. 매 방송 시작 순서
------------------------------------------------------------
1) Chrome에서 관리자 화면에 로그인합니다.
2) 신청곡 관리에서 이전 방송 신청곡이 남아 있는지 확인합니다.
   새 방송을 시작하려면 필요한 경우 '신청곡 초기화'를 사용합니다.
   초기화는 기존 목록을 초기화하고 새 목록으로 시작하는 기능입니다.
3) '채팅 신청 허용'과 '빠른 신청'을 원하는 상태로 설정합니다.
4) SOOP 방송 페이지를 열고 채팅 감지기가 켜져 있는지 확인합니다.
5) OBS의 신청곡/가사 브라우저 소스가 켜져 있는지 확인합니다.
6) 부를 신청곡을 '현재곡'으로 지정합니다.
7) 가사 오버레이 영역에서 기본 가사와 기본 MR이 준비됐는지 확인합니다.
8) '별도 창 MR 재생 준비'를 누릅니다.
9) 'YouTube 재생 탭 열기'를 누르고 열린 YouTube에서 재생합니다.
10) 관리자에 연결 상태가 나타나고 OBS 가사가 움직이는지 확인합니다.

방송 중 유지할 창:
  - 관리자 화면: 재생 연결 및 자동 가사/번역 작업
  - YouTube 탭: MR 실제 재생
  - SOOP 방송 페이지: 채팅 신청 감지
  - OBS: 방송 출력

관리자의 상단 메뉴는 화면을 분리하는 탭이 아니라,
신청곡 관리 / 가사 오버레이 / OBS 오버레이 / 노래 목록으로 이동하는 북마크입니다.


6. 곡 추가 / 수정 / 삭제
------------------------------------------------------------
[추가]
관리자 오른쪽 아래 원형 '+' 버튼을 누릅니다.
곡명, 가수, 숙련도 등을 입력하고 '노래 추가'를 누릅니다.

장르:
  - 비워 두면 Gemini가 자동 분류합니다.
  - 최대 3개이며 적합한 것이 1~2개면 그 수만 선택합니다.
  - 직접 선택한 장르를 우선합니다. 추가 후에도 수정할 수 있습니다.
  - 자동 분류 실패 시에도 곡은 저장되며 장르는 나중에 직접 지정할 수 있습니다.

가사:
  - 기본적으로 Apple Music 계열의 시간정보 있는 가사를 자동 검색합니다.
  - Gemini가 생성한 곡명/가수 별칭도 검색에 활용됩니다.
  - '가사 매칭 중'에는 기다려 주세요.
  - 가사 매칭을 30초 기다린 뒤에도 준비되지 않으면 실패 알림이 나올 수 있습니다.
    이 경우 곡 자체는 저장되어 있으므로 같은 곡을 반복해서 추가하지 마세요.
  - 관리자 화면을 열어 두면 대기 중인 자동 작업이 이어질 수 있습니다.
  - 장르 분류 시간이 따로 있어서 전체 곡 추가 시간이 30초보다 길 수 있습니다.

앨범 커버:
  - 연결된 Apple Music 가사/트랙 정보로 커버를 가져옵니다.
  - 정보가 없거나 가져오기 실패 시 기본 그림이 나올 수 있습니다.

[수정]
노래 목록에서 해당 곡의 수정 버튼을 누릅니다.
곡명/가수/별칭이 잘못됐으면 고친 뒤 저장하세요.
자동 검색 결과는 틀릴 수 있으므로 다른 버전이 잡히면 수동선택을 사용하세요.

[삭제]
곡 삭제는 노래책에서 곡을 영구적으로 지우는 기능입니다.
해당 곡의 신청 기록, 가사, 번역, MR도 함께 삭제됩니다.
신청 한 건만 빼려면 곡을 삭제하지 말고 신청곡 관리에서 취소하세요.
복구 버튼은 없습니다. 부르는 중인 곡은 재생을 먼저 정지하세요.


7. 기본 가사 / 기본 MR 설정
------------------------------------------------------------
노래 목록에서 '가사/MR' 관리 버튼을 엽니다.

기본 가사와 기본 MR은 실제 재생과 오버레이가 사용할 대표 항목입니다.
각각 하나뿐이면 자동으로 기본값이 됩니다.
여러 개가 있으면 사용할 항목을 기본으로 지정하세요.

[가사 수동선택]
자동 가사가 없거나 다른 곡/버전이면 '가사 수동선택'에서 검색합니다.
결과의 곡명·가수·가사 내용·시간정보를 확인하고 원하는 버전을 저장합니다.
필요하면 '기본 가사로 설정'을 누릅니다.
수동으로 고른 기본 가사는 자동 선택의 예외로 유지됩니다.

표시 의미:
  빨간색 '가사가 연결되지 않았습니다.' : 기본 가사가 없는 상태
  주황색 '시간 정보가 존재하지 않습니다.' : 텍스트 가사는 있지만 자동 싱크 불가
  작업 중/재시도 안내 : 잠시 기다리거나 수동선택 가능

[MR]
YouTube MR URL을 입력해 저장합니다.
MR은 실제로 부를 반주 영상으로 직접 선택해야 합니다.
가사 자동 검색이 MR까지 자동 등록해 주는 것은 아닙니다.
MR 추가/수정/기본값 변경은 가사 오버레이 영역에 자동 반영됩니다.
반영되지 않으면 연결 상태를 확인하고 잠시 기다린 뒤 재생을 다시 준비하세요.


8. MR 재생과 가사 싱크
------------------------------------------------------------
1) 신청곡 관리에서 부를 곡을 현재곡으로 지정합니다.
2) 기본 MR과 시간정보 있는 기본 가사를 준비합니다.
3) 가사 오버레이에서 '별도 창 MR 재생 준비'를 누릅니다.
4) 'YouTube 재생 탭 열기'를 누르고 열린 탭의 연결 상태를 확인합니다.
5) YouTube 탭에서 재생 / 일시정지 / 탐색바 이동을 조작합니다.

영상 내부 재생 시간을 기준으로 가사가 움직입니다.
관리자에서 현재곡만 지정하고 MR을 재생하지 않으면 가사가 자동 진행되지 않습니다.
MR은 노래책 안이 아니라 일반 YouTube 탭에서 재생합니다.
새 창으로 분리하고 싶으면 YouTube 탭을 바깥으로 끌어내면 됩니다.

[오프셋]
가사가 반주보다 먼저 나오면 양수 방향으로 조절합니다.
가사가 반주보다 늦게 나오면 음수 방향으로 조절합니다.

  +1000ms = 가사를 1초 늦게 표시
  -1000ms = 가사를 1초 빨리 표시
  100ms = 0.1초

입력 조절 단위는 100ms이며 변경하면 자동 저장됩니다.
별도 저장 버튼은 없습니다.
MR 영상의 전주/편집 때문에 곡마다 조정값이 다를 수 있습니다.
영상 전체가 아닌 중간부터 지속적으로 어긋나면 다른 버전의 가사인지 확인하세요.

[가사 표시]
  - 일반 곡: 한 줄 표시
  - J-POP 장르 포함 곡: 위에 작은 원문, 아래에 한국어 번역
  - 번역 글씨 크기는 기존 한국어 가사와 같습니다.
  - 팝만 지정된 곡: 원문만 표시
  - J-POP 번역은 관리자에서 현재곡으로 지정한 뒤 처음 생성합니다.
  - 번역 준비 전이나 실패 중에는 원문만 보입니다.
  - 한 번 준비된 번역은 저장해 다음에도 재사용합니다.
  - 연결된 원문 가사가 바뀌면 번역을 다시 준비할 수 있습니다.
  - 번역 준비가 늦으면 관리자 화면을 열어 둔 채 잠시 기다려 주세요.
  - 번역의 표현/뉘앙스가 완벽하다고 보장되지는 않습니다.

가사 전환은 0.5초 교차 페이드입니다.
이전 줄 끝과 다음 줄 시작이 5초 이내면 다음 줄까지 유지합니다.
간격이 더 길면 이전 가사를 지워 간주 동안 계속 남지 않게 합니다.
관리자 미리보기의 노란 단어 진행 표시와 OBS의 표시 형태는 다릅니다.

[오디오]
가사 오버레이는 YouTube 소리를 재생하지 않습니다.
OBS에서 YouTube를 재생하는 Chrome의 소리가 들어오는지 오디오 미터로 확인하세요.
데스크톱 오디오와 별도 앱 오디오를 동시에 잡으면 소리가 겹칠 수 있습니다.
송출 전 짧게 녹화해서 반주·마이크·가사 싱크를 확인하세요.


9. OBS 오버레이 설정
------------------------------------------------------------
신청곡과 가사는 별도 브라우저 소스로 추가합니다.

[신청곡 소스]
1) OBS의 원하는 장면에서 소스 추가 > 브라우저를 선택합니다.
2) 이름을 '노래책 신청곡'처럼 정합니다.
3) 로컬 파일 대신 다음 URL을 입력합니다.
   https://g12songbook.vercel.app/overlay/requests
4) 1920 x 1080 캔버스 기준 너비 1920, 높이 1080으로 설정합니다.
5) 기본 투명 배경으로 사용하고 화면 위치를 확인합니다.

[가사 소스]
같은 방법으로 '노래책 가사' 소스를 추가합니다.
URL: https://g12songbook.vercel.app/overlay/lyrics
1920 x 1080 캔버스라면 동일 크기로 설정합니다.
가사가 캐릭터나 다른 화면 뒤에 가려지면 OBS 소스 순서를 조정하세요.

다른 해상도로 방송한다면 OBS 캔버스에 맞게 소스 크기를 설정하세요.
위 주소는 로그인 없이 표시됩니다. OBS 내부에서 관리자 로그인을 하지 않습니다.

[설정 변경]
관리자 > OBS 오버레이 설정에서 위치, 크기, 밝게/어둡게,
표시 개수, 빈 신청곡 표시 여부를 바꿉니다.
설정은 자동 저장되어 기존 OBS URL에 적용됩니다.
바꿀 때마다 URL을 새로 복사할 필요가 없습니다.

가사 글씨 색상은 관리자 > 가사 오버레이에서 변경합니다.
신청곡 테마 설정과 가사 글씨 색상은 별개입니다.

[QR]
'QR 오버레이 표시'를 켜면 시청자가 노래책으로 접속할 수 있는 QR이 나옵니다.
신청곡 위치가 왼쪽이면 QR은 오른쪽 아래,
신청곡 위치가 오른쪽이면 QR은 왼쪽 아래에 나옵니다.
QR을 스캔하면 시청자용 노래책으로 접속합니다.
별도 QR 브라우저 소스를 추가하지 않아도 신청곡 오버레이에 함께 표시됩니다.

[브라우저에서 미리 확인]
OBS 없이 Chrome에서 오버레이 URL을 열어도 동일한 상태를 확인할 수 있습니다.
신청곡이 없고 빈 목록 숨김이 켜져 있으면 아무것도 안 보이는 것이 정상입니다.
가사도 현재곡·재생·시간정보가 준비되지 않았거나 간주 중이면 비어 있을 수 있습니다.
OBS에서만 안 보이면 브라우저 소스 새로고침과 URL/크기/소스 순서를 확인하세요.


10. 신청곡 처리와 방송 종료
------------------------------------------------------------
[채팅 신청 허용]
켜면 SOOP 채팅 신청을 접수합니다. 끄면 채팅 신청을 차단합니다.
관리자 수동 신청과 빠른 신청 설정은 별도로 확인하세요.

[빠른 신청]
켜면 공개 노래책 곡 카드에 신청 버튼이 표시됩니다.
빠른 신청으로 추가한 항목은 관리자에서 신청자가 '빠른 신청'으로 표시됩니다.
공개 메인 신청곡 영역에는 신청자를 표시하지 않습니다.

[현재곡]
지금 부를 신청곡을 현재곡으로 지정합니다.
YouTube 재생 준비/연결은 가사 오버레이 영역에서 별도로 진행합니다.

[완료]
노래를 실제로 불렀으면 완료 처리합니다.
완료 처리 시 곡의 '마지막으로 부른 날'이 한국 시간 기준 오늘로 기록됩니다.
이 날짜는 공개 목록 정렬과 채팅 동명곡 선택 기준으로 사용됩니다.

[취소]
부르지 않을 신청은 취소합니다. 취소는 부른 날짜 기록을 갱신하지 않습니다.
완료/취소된 항목은 관리자 목록 아래쪽으로 이동합니다.

[신청곡 초기화]
방송을 종료하고 현재 신청곡 목록을 새로 시작합니다.
방송 초기화 자체는 과거 신청 기록을 보존합니다.
곡 삭제와 다릅니다. 곡을 삭제할 때는 그 곡의 모든 신청 기록도 삭제됩니다.

방송 종료 권장 순서:
  1) YouTube 반주 정지
  2) 부른 곡 완료 처리
  3) 채팅 신청/빠른 신청 접수 종료
  4) 필요하면 신청곡 초기화
  5) OBS 방송 종료 후 관리자/YouTube/SOOP 탭 닫기


11. 문제 해결 빠른 안내
------------------------------------------------------------
Q. 관리자 로그인이 안 됩니다.
A. 관리자 이메일/비밀번호와 접속 주소를 확인하세요.
   운영 계정은 미리 준비되어 있어야 합니다.
   계속 로그인할 수 없으면 노래책 제작자에게 계정 확인을 요청하세요.

Q. 채팅에 !신청을 쳤는데 안 들어옵니다.
A. 아래 순서대로 확인합니다.
   1) 관리자에서 채팅 신청 허용이 켜져 있는가?
   2) Tampermonkey와 채팅 감지기가 켜져 있는가?
   3) CONFIG가 예제 값이 아닌 실제 공개 URL/anon key인가?
   4) https://play.sooplive.com/ 방송 페이지인가?
   5) 확장 프로그램의 사용자 스크립트 허용이 켜져 있는가?
   6) 설치 후 SOOP 페이지를 새로고침했는가?
   7) 등록된 곡명/별칭과 일치하는가? 가수 - 곡명으로도 시도했는가?
   8) 같은 신청자의 같은 곡이 이미 대기/진행 중인가?
   9) 방금 새로 보낸 채팅인가? 과거 메시지는 재처리하지 않는다.
   계속 안 되면 보낸 신청 문구와 화면을 캡처해 제작자에게 전달하세요.
   SOOP 화면 변경으로 감지기가 동작하지 않을 때는 설치 파일 업데이트가 필요합니다.

Q. 동명곡이 여전히 실패합니다.
A. 설치된 채팅 감지기가 1.3.1 이상인지 확인하세요.
   최신 파일을 받았더라도 Tampermonkey에 설치한 내용을 교체해야 적용됩니다.

Q. 가사는 있는데 OBS에서 안 나옵니다.
A. 현재곡 지정, 기본 MR, 기본 가사, 시간정보를 확인하세요.
   재생 준비 후 버튼으로 연 YouTube 탭에서 재생해야 합니다.
   전주/간주에는 표시할 가사가 없을 수 있습니다.
   색상이 배경과 같거나 OBS에서 소스가 가려졌는지도 확인하세요.

Q. YouTube 연결이 안 됩니다.
A. 관리자와 YouTube가 같은 Chrome 프로필인지 확인하세요.
   MR 브리지가 켜져 있는지 확인하고 팝업 차단을 해제합니다.
   '재생 다시 준비' 후 새로 열린 재생 탭을 사용하세요.
   여러 관리자 창에서 동시에 재생 준비를 누르지 마세요.
   관리자/YouTube 새로고침 후에는 다시 준비해야 할 수 있습니다.

Q. 화면은 멈췄는데 가사가 진행하거나 싱크가 틀립니다.
A. 관리자 연결 상태와 YouTube 광고/버퍼링 여부를 확인합니다.
   연결이 불안정하면 일시정지 후 재생을 다시 준비하세요.
   다른 노래 버전이나 MR 전주 길이 차이는 오프셋 또는 가사 선택으로 조정합니다.

Q. 가사 매칭 실패 알림이 떴습니다.
A. 먼저 노래 목록에 곡이 이미 추가됐는지 확인하세요.
   곡명/가수/공식 영문명 별칭을 확인한 뒤 가사 수동선택을 사용합니다.
   가사 제공처에 해당 곡이 없거나 일시적으로 검색되지 않을 수도 있습니다.
   시간정보 없는 가사만 있으면 자동 싱크는 사용할 수 없습니다.

Q. J-POP 번역이 안 보입니다.
A. 곡 장르에 J-POP이 있는지, 시간정보 있는 기본 가사가 있는지 확인하세요.
   관리자 화면에서 현재곡으로 선택하고 번역 준비 상태를 기다립니다.
   여러 곡에서 계속 실패하면 제작자에게 점검을 요청하세요.
   팝만 지정된 곡은 원문만 표시하는 것이 정상입니다.

Q. MR 추가 후 바로 적용되지 않습니다.
A. 여러 MR 중 사용할 MR이 기본으로 지정됐는지 확인하세요.
   연결이 정상이라면 자동 갱신됩니다. 재생 중 MR을 바꾸면 다시 준비하세요.

Q. 글꼴이 평소와 다릅니다.
A. 인터넷 연결 문제로 글꼴을 불러오지 못하면 기본 글꼴로 보일 수 있습니다.
   연결을 확인하고 페이지를 새로고침해 보세요.
   가사 오버레이의 규리의 일기 글꼴은 별도입니다.

Q. 개발자 PC가 꺼지면 사이트도 꺼집니까?
A. 위 운영 사이트는 제작자 PC가 꺼져 있어도 사용할 수 있습니다.
   전달받은 테스트용 주소 대신 이 설명서의 운영 주소를 사용하세요.
   단, 방송 중 사용하는 본인의 관리자/YouTube/SOOP 탭은 열어 두어야 합니다.
